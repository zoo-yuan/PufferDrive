3. 引擎指标缺口（桥接层工作清单）

3 条模板的谓词依赖 metrics_array 里不存在的指标，这些指标必须由桥接层提供，否则约束无法自动挖 case。
缺失指标被哪些模板使用说明
crosswalk_clearance_m斑马线未让行需要 crosswalk 几何 + ego 位置的距离；metrics_array 无此指标（无斑马线时取大值）
pedestrian_clearance_m行人过近距离需要 agent_type=predict 的行人 + 最小间距；metrics_array 无此指标（无行人时取大值）
junction_occupancy汇入未让行需要路口区域占用（overlap/junction），metrics_array 无此指标（未占用=0）

注：谓词可执行 ≠ 场景可解。可行性裁判还要用 IDM / REPLAY / STATIC 在同一场景各跑一遍；全挂即场景不可解，禁止进 RL（ADR-0007）。
