3. 这批数据的地图覆盖缺口

3 条 bag 没有可解析的 base_map.bin（对应地图目录只有 21 GB / 34 GB 的 base_map.txt）。这些 bag 的 8 条车道类约束无法挖掘，只能等对应地图的 bin 落地。这不是匹配算法的问题，是数据供给问题 —— 但会直接决定哪些 bag 能进 bad case 库。

补 bin 的命令（在 Apollo 地图目录执行）：protoc --encode=apollo.hdmap.Map hdmap_map.proto < base_map.txt > base_map.bin，或从 Apollo 工具链导出。
